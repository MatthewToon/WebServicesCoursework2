# Web Services Coursework 2

Repository for COMP3011 Coursework 2: a Python search tool for `https://quotes.toscrape.com/`.

## Running

Start the shell from the repository root:

```bash
python -m src.main
```

At this stage of development, `load`, `print <word>`, and `find <query terms>` are wired into the shell. The `build` command is added later with the crawler.

The final tool supports:

- `build`
- `load`
- `print <word>`
- `find <query terms>`
- `help`
- `exit`
